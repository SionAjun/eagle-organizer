# Eagle MCP（本地版）

让 Claude（Desktop / Code / Codex）直接查、看、打标 Eagle 图库。

- 上游：tuki0918/eagle-mcp-server，`fastmcp-stdio` 分支（commit 55263338），MIT
- 本地改动：
  - 新增 `find_items`：按标签/关键词搜，只回精简字段（省 token）
  - 新增 `view_items`：一次看 1–8 张缩略图（压到 640px）
  - 新增 `add_item_tags`：只加标签，不动原有标签（`update_item` 会整组替换，慎用）
  - 关掉 `move_item_to_trash`（删图不该交给 AI）
  - 依赖加了 pillow（缩略图用）

## 安装

1. 双击 `install_eagle_mcp.bat`
2. 完全退出 Claude Desktop（托盘右键 Quit），再打开
3. 用的时候 Eagle 要开着

脚本会：没有 uv 就装 uv → 装依赖（第一次会下载 Python 3.13）→ 备份并写入 Claude Desktop 配置（名字 `eagle`）→ 如果装了 Claude Code / Codex，顺带注册。DSH 没注册。

## 卸载

把 `claude_desktop_config.json` 里 `mcpServers` 下的 `eagle` 删掉（同目录有 `.bak-日期` 备份），再删这个文件夹。
